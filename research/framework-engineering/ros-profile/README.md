# ROS–Framework Engineering Profile v1.0

This profile is the domain contract between Research Operating System (ROS) 1.0.0 and Framework Engineering (FE). ROS owns generic research identity, lifecycle, provenance, evidence, confidence, completion, supersession, execution governance, journals, handoffs, and deterministic registries. FE adds only the vocabulary and rules needed to observe, decompose, compare, and test frameworks.

The executable slice is intentionally narrow: a registered discovery stream, one synthetic provider execution, one source, one framework, one Framework Genome, one case study, generated indexes, and an FE-extension validator. It does not claim ROS is complete or change FE theory.
