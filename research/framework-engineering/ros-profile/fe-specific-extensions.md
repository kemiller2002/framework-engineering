# FE-specific extensions

FE owns framework records, Framework Genomes, framework case studies, postmortems, retrospectives, comparative studies, observations, contradictions, hypotheses, syntheses, and experiment proposals. It also owns observational taxonomies for properties, mechanisms, contexts, outcomes, families, and failure modes.

All eleven candidate record types are justified because their required fields describe frameworks or framework research. Their executable shapes are in `schemas/fe-record.schema.json`. They inherit the ROS envelope and must not redefine generic evidence, provenance, lifecycle, confidence, completion, or execution metadata.

Taxonomy frequency is descriptive, never evidence that a property is beneficial.
