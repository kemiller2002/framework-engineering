# Adversarial Review Template

After blinded scoring and before unblinding, assign an independent critic to actively seek evidence against the candidate principle. Answer:

1. Where did explicit uncertainty improve the result?
2. Where did it merely add hedging?
3. Where did lineage reveal a reasoning defect?
4. Where was lineage ceremonial rather than useful?
5. Did any variant conceal weak reasoning behind formal structure?
6. Did the baseline reach a better result more efficiently?
7. Did either property become more valuable as ambiguity increased?
8. What result most strongly contradicts the candidate principle?
9. What modification would make the principle more precise?
10. Should uncertainty and lineage remain one principle or become separate principles?

Record source output IDs, not framework identities. This file is a template until review occurs.
